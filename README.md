# Final Project

## AI-Based Web Application Development and Deployment

This project is an AI-based emotion detection web application developed using Python, Flask, and IBM Watson NLP.

### Project Components

- `emotion_detection.py` - Emotion detection function using Watson NLP.
- `EmotionDetection/` - Python package containing the emotion detection module.
- `server.py` - Flask web server.
- `test_emotion_detection.py` - Unit tests for emotion detection.
- `templates/index.html` - Web application interface.
- `static/mywebscript.js` - Front-end JavaScript.

### Features

- Detects anger, disgust, fear, joy, and sadness.
- Identifies the dominant emotion.
- Provides formatted emotion analysis through a Flask web application.
- Handles blank or invalid input.
- Includes unit testing.
- Includes PyLint static code analysis with a 10/10 score.
